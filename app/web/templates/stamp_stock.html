印花税 — 香港股票转让

已支持：可计算（已批准税项）

按每份文书独立估算香港股票转让印花税；结果仅为估算，不是税务局评税或专业意见。

计算入口：本页为说明页；计算经 API 三段确认执行（见下）。

计算入口

对应执行端点：POST /api/v1/calc/stamp-duty/stock——先 POST /api/v1/calc/prepare 提交事实取得 prepared_id，再确认后执行。

文书清单完整性（complete）未确认为完整时，系统只追问、不给交易总额。

覆盖说明

  • 成交单据（contract note）：每份 sold note 与每份 bought note 各按代价或价值的 0.1%（不是取较高者），每份分别计算。
  • 自愿在生处置：5 港元＋股票价值的 0.2%；其他转让：每份 5 港元。
  • 2023-11-17 之前的文书规则不在首版范围；印花税无一次性税务宽减。
